# Kapitel 44.3 — UI (Widgets)

> **Leitgedanke:** Das UI-System ist **Immediate-Mode** (jeden Frame neu aufgebaut, kein
> persistenter Widget-Baum) und rendert direkt via OpenGL/OpenGL ES — kein externer Dep.
> Das Layout-Modell basiert auf einem **Grid-System** mit f32-Größenangaben (0.0–1.0),
> Rowspan/Colspan und beliebiger Verschachtelung.
> Alle Größen sind normalisiert — kein einziger hardcodierter Pixelwert im Layout.
> Das Grid skaliert automatisch auf jede Auflösung und Plattform.

---

## Architektur

```
┌─────────────────────────────────────────────────────────────┐
│  Widget-API       ui.label / ui.button / ui.progress_bar    │
│                   ui.begin_grid / ui.begin_cell              │
├─────────────────────────────────────────────────────────────┤
│  Layout-Engine    Grid → Zell-Rects berechnen               │
│                   Rowspan/Colspan → Merge-Rects              │
│                   f32-Größen → Pixel-Rects (mit DPI-Scale)   │
├─────────────────────────────────────────────────────────────┤
│  2D Batch-Renderer  Draw-List aufbauen (Quads, Text-Quads)  │
│                     ui.end() → ein Flush nach OpenGL         │
├─────────────────────────────────────────────────────────────┤
│  Text-Renderer    stb_truetype (single-header)              │
│                   Font-Atlas (Bitmap) auf GPU-Textur         │
└─────────────────────────────────────────────────────────────┘
```

`ui.begin()` startet einen neuen UI-Frame und setzt den Draw-List zurück.
Alle Widget-Calls zwischen `begin` und `end` bauen den Draw-List auf.
`ui.end()` berechnet Layouts, führt Hit-Tests durch und flusht alles nach OpenGL.

## 2. Frame-Lifecycle

| Aufruf | Beschreibung |
|--------|--------------|
| `ui.begin(win: window_handle)` | UI-Frame starten; Draw-List zurücksetzen, Fenstergröße einlesen |
| `ui.end()` | Layout berechnen, Hit-Tests durchführen, Draw-List nach OpenGL flushen |

Muss im `render`-Callback **nach** `gl.clear_all` aufgerufen werden —
UI liegt immer über der 3D-Szene.

## 3. Grid-Layout

### 3.1 Größen-Einheiten

Spalten- und Zeilengrößen werden als **`buffer<f32>`** übergeben.
Jeder Wert steht für den Anteil am verfügbaren Raum:

| Wert | Bedeutung |
|------|-----------|
| `0.0 < x < 1.0` | Fixer Anteil: `0.2` = 20% des verfügbaren Raums |
| `1.0` | **Flexibel**: nimmt den nach Abzug aller fixen Anteile verbleibenden Raum; mehrere `1.0`-Einträge teilen den Rest gleichmäßig auf |

**Beispiele:**

```
[0.2, 1.0, 0.2]   →  20%  |  60% (Rest)  |  20%
[0.15, 1.0, 0.15] →  15%  |  70% (Rest)  |  15%
[1.0, 1.0, 1.0]   →  33%  |  33%         |  33%  (drei gleich breite Spalten)
[0.3, 0.7]        →  30%  |  70%
[1.0]             →  100% (einzelne Spalte)
```

### 3.2 Grid-Befehle

| Aufruf | Beschreibung |
|--------|--------------|
| `ui.begin_grid(cols: buffer<f32>, rows: buffer<f32>)` | Grid aufspannen |
| `ui.end_grid()` | Grid abschließen |
| `ui.set_gap(h: f32, v: f32)` | Abstand zwischen Zellen in logischen Pixeln; muss vor `begin_grid` gesetzt werden |

### 3.3 Zellen

```aiml
- call: [ui.begin_cell, col, row, colspan, rowspan]
```

| Parameter | Typ | Beschreibung |
|-----------|-----|--------------|
| `col` | `i32` | Spaltenindex (0-basiert) |
| `row` | `i32` | Zeilenindex (0-basiert) |
| `colspan` | `i32` | Anzahl überspannter Spalten (`1` = keine Überspannung) |
| `rowspan` | `i32` | Anzahl überspannter Zeilen (`1` = keine Überspannung) |

```aiml
- call: [ui.end_cell]
```

Alle vier Parameter sind immer anzugeben — AIML hat keine Default-Parameter.
Eine Zelle mit `colspan=2, rowspan=2` belegt die vier Zellen
`(col,row)`, `(col+1,row)`, `(col,row+1)`, `(col+1,row+1)` —
identisch zu HTML `<td colspan="2" rowspan="2">`.
In belegte Zellen darf nicht geschrieben werden.

### 3.4 Inhalts-Ausrichtung

Vor `begin_cell` setzen, wirkt nur für die nächste Zelle:

```aiml
- call: [ui.set_align, h, v]
```

`h`: `"left"` / `"center"` / `"right"`
`v`: `"top"` / `"middle"` / `"bottom"`

### 3.5 Verschachtelung

Innerhalb einer Zelle kann ein Sub-Grid geöffnet werden.
Die Zellgröße wird zum neuen 100%-Basis des Sub-Grids.

```aiml
- call: [ui.begin_cell, 1, 1, 1, 1]
  - call: [ui.begin_grid, [0.5, 0.5], [0.5, 0.5]]
  - call: [ui.begin_cell, 0, 0, 1, 1]
  - call: [ui.button, "A"]
  - call: [ui.end_cell]
  - call: [ui.begin_cell, 1, 0, 1, 1]
  - call: [ui.button, "B"]
  - call: [ui.end_cell]
  - call: [ui.end_grid]
- call: [ui.end_cell]
```

## 5. Style-System

Styles werden als Push/Pop-Stack verwaltet — `push` überschreibt Properties temporär,
`pop` stellt den vorherigen Stand wieder her.

```aiml
- decl: [s, ui_style]
- set: [s.font_size,     24.0]
- set: [s.color,         0xFFFFFFFF]   # RGBA: Weiß, voll opak
- set: [s.bg_color,      0x1A1A2EFF]
- set: [s.border_color,  0x4444AAFF]
- set: [s.border_width,  1.0]
- set: [s.corner_radius, 6.0]
- call: [ui.push_style, s]
- call: [ui.label, "Styled Text"]
- call: [ui.pop_style]
```

### `ui_style` — Member

| Member | Typ | Default | Beschreibung |
|--------|-----|---------|--------------|
| `font` | `ui_font` | Default-Font | Aktiver Font |
| `font_size` | `f32` | `16.0` | Schriftgröße in logischen Pixeln |
| `color` | `i32` | `0xFFFFFFFF` | Vordergrundfarbe (Text, Icons) als RGBA |
| `bg_color` | `i32` | `0x00000000` | Hintergrundfarbe |
| `hover_color` | `i32` | `0x3333AAFF` | Hintergrund bei Hover |
| `active_color` | `i32` | `0x5555CCFF` | Hintergrund bei Klick/Aktiv |
| `border_color` | `i32` | `0x00000000` | Rahmenfarbe |
| `border_width` | `f32` | `0.0` | Rahmenbreite in logischen Pixeln |
| `corner_radius` | `f32` | `0.0` | Eckenradius in logischen Pixeln |
| `padding_h` | `f32` | `8.0` | Horizontales Innen-Padding |
| `padding_v` | `f32` | `4.0` | Vertikales Innen-Padding |
| `opacity` | `f32` | `1.0` | Transparenz (0.0 = unsichtbar, 1.0 = voll opak) |

Globales Theme (Basis des Style-Stacks):

```aiml
- call: [ui.set_default_style, s]
```

## 6. Font-System

| Aufruf | Rückgabe | Beschreibung |
|--------|----------|--------------|
| `ui.load_font(p: path, size: f32)` | `ui_font` | TTF-Font laden; Atlas bei `size` logischen Pixeln backen |
| `ui.load_font_default(size: f32)` | `ui_font` | Eingebetteten Default-Font (Proggy Clean) laden |
| `ui.set_default_font(font: ui_font)` | — | Default-Font für alle folgenden Widgets |

Fonts werden als Bitmap-Atlas auf eine GPU-Textur gebacken (stb_truetype).
Mehrere Größen desselben Fonts = mehrere Atlas-Texturen.

## 7. Input-Integration

Die UI konsumiert automatisch Events aus der `input`-Queue.
Widget-IDs (FNV1a-Hash des `id`-Strings) verhindern State-Konflikte.

| Event | Verarbeitung |
|-------|-------------|
| `mouse_move` | Hover-State aller Widgets aktualisieren |
| `mouse_button_down` | Hit-Test → aktives Widget setzen |
| `mouse_button_up` | Klick-Resultat für `ui.button` auslösen |
| `text` | In fokussiertes `ui.text_input` / `ui.text_area` schreiben |
| `key_down "Backspace"` | Im fokussierten Textfeld löschen |
| `key_down "Tab"` | Focus zum nächsten Widget weitergeben |

`ui.end()` konsumiert verarbeitete Events aus der Queue.
Klicks ins Leere verbleiben in der Queue (für Spiellogik nutzbar).

- def:
    name: render
    args: []
    body:
      - call: [gl.clear_all, 0.05, 0.05, 0.1, 1.0]

      # Zeilen:  10% | Rest | 15%

      # Oben links: Spieler-Status (col=0, row=0, keine Überspannung)
      - call: [ui.set_align, "left", "top"]

      - call: [ui.set_align, "center", "top"]

      - call: [ui.label_colored, "SCORE: ${score}", 0xFFDD44FF]
      - call: [ui.end_cell]

      # Oben rechts: Munition (col=2, row=0)
      - call: [ui.set_align, "right", "top"]

        - call: [ui.image, slot1_tex]
        - call: [ui.end_cell]
        - call: [ui.begin_cell, 1, 0, 1, 1]
        - call: [ui.image, slot2_tex]
        - call: [ui.end_cell]
        - call: [ui.begin_cell, 2, 0, 1, 1]
        - call: [ui.image, slot3_tex]
        - call: [ui.end_cell]
        - call: [ui.begin_cell, 3, 0, 1, 1]
        - call: [ui.image, slot4_tex]
        - call: [ui.end_cell]
        - call: [ui.end_grid]
      - call: [ui.end_cell]

      - call: [ui.end_grid]
      - call: [ui.end]

## 9. Vollständiges Beispiel: Pause-Menü

```aiml
- def:
    name: render_pause
    args: []
    body:
      - call: [gl.clear_all, 0.0, 0.0, 0.0, 0.5]   # halbtransparenter Overlay
      - call: [ui.begin, win]

      # Äußeres Grid: zentriertes Panel (mittlere 40% × 60%)
      - call: [ui.begin_grid, [0.3, 0.4, 0.3], [0.2, 0.6, 0.2]]
      - call: [ui.begin_cell, 1, 1, 1, 1]

        # Inneres Grid: Menü-Einträge vertikal
        # 4 Buttons à 15%, Rest = Leerraum unten
        - call: [ui.begin_grid, [1.0], [0.12, 0.15, 0.15, 0.15, 1.0]]

        - call: [ui.set_align, "center", "middle"]
        - call: [ui.begin_cell, 0, 0, 1, 1]
        - call: [ui.label, "PAUSED"]
        - call: [ui.end_cell]

        - call: [ui.set_align, "center", "middle"]
        - call: [ui.begin_cell, 0, 1, 1, 1]
        - decl: [resume, bool, { call: [ui.button, "Resume"] }]
        - if: [{ ==: [resume, true] }, true]
          then:
            - set: [paused, false]
        - call: [ui.end_cell]

        - call: [ui.set_align, "center", "middle"]
        - call: [ui.begin_cell, 0, 2, 1, 1]
        - decl: [settings, bool, { call: [ui.button, "Settings"] }]
        - if: [{ ==: [settings, true] }, true]
          then:
            - call: [open_settings]
        - call: [ui.end_cell]

        - call: [ui.set_align, "center", "middle"]
        - call: [ui.begin_cell, 0, 3, 1, 1]
        - decl: [do_quit, bool, { call: [ui.button, "Quit"] }]
        - if: [{ ==: [do_quit, true] }, true]
          then:
            - call: [engine.quit, win]
        - call: [ui.end_cell]

        - call: [ui.end_grid]

      - call: [ui.end_cell]
      - call: [ui.end_grid]
      - call: [ui.end]
```

## 10. Implementierungshinweise

### 10.1 Logische Pixel

Alle Größen in Style-Properties und `spacer`/`image_sized` sind **logische Pixel**,
automatisch skaliert mit `engine.dpi()`:

```
physische_pixel = logische_pixel × engine.dpi()
```

Grid-Größen (`buffer<f32>`) sind dimensionslos normalisiert — sie referenzieren
nie direkt Pixel.

### 10.2 Layout-Berechnung in `ui.end()`

1. Root-Rect = Fenstergröße in physischen Pixeln
2. Pro Grid: fixe Anteile (`< 1.0`) summieren und von Gesamtbreite/-höhe abziehen
3. Verbleibender Rest gleichmäßig auf alle `1.0`-Einträge aufteilen
4. Gap abziehen: `cell_size -= gap × (count - 1) / count`
5. `begin_cell_span`: Zell-Rect = Union der `colspan × rowspan` Einzel-Rects minus innere Gaps
6. Nested Grid: Zell-Rect wird neues Root-Rect

### 10.3 Batch-Renderer

Ein Vertex-Buffer (Position xy, UV, RGBA Color) wird pro `ui.end()` gefüllt.
Textur-Wechsel (Font-Atlas ↔ Bild-Textur) erzeugen Sub-Batches —
ein Draw-Call pro Textur-Gruppe.
Abgerundete Rechtecke werden als Quads + SDF-Shader-Trick gerendert
(kein Tessellieren der Ecken nötig).

### 10.4 stb_truetype

```cpp
// In ui_runtime.cpp (einmalig):
#define STB_TRUETYPE_IMPLEMENTATION
#include "../vendor/stb_truetype.h"
```

Font-Atlas wird als `GL_ALPHA`-Textur hochgeladen.
Text-Quads blenden mit `color × texture.a` — beliebige Textfarbe ohne
Atlas-Neugenerierung.

### 10.5 Widget-State

```cpp
struct WidgetState { bool hovered; bool active; bool focused; };
unordered_map<uint32_t, WidgetState> widget_states;  // Key = FNV1a(id)
```

State wird zwischen Frames gehalten. Am Frame-Ende werden States von
Widgets die in diesem Frame nicht aufgerufen wurden automatisch entfernt.
